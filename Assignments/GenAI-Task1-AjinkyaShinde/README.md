## Task 1: Product Collections (Lists & Tuples)
Create a product list with at least 6 products, create a sample product tuple, print selected products, and add two new products.

## Task 2: Categories (Sets)
Create a category set, add a new category, check whether a category exists, and find the total number of unique categories.

Create a product catalog using tuples, map categories to product names, and print products from the category having the maximum number of products.
